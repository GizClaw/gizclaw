# Test CLI

## User Story

As a developer, I want `gizclaw test` to validate and run declarative Peer scenarios from the command line.

## Covered Behaviors

- `gizclaw test validate` checks Giztest documents without connecting to a server.
- `gizclaw test run` executes one or more Giztest documents against configured Peer endpoints.
- `gizclaw test play` records and replays a single Giztest scenario with bounded output artifacts.
