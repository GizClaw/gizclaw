# pkgs/audio/songs

[源码](https://github.com/GizClaw/gizclaw/tree/main/pkgs/audio/songs)

保存内置 song、note、tempo、voice 与 metronome definitions，并把乐谱渲染为 PCM chunks。

[Go API References](https://pkg.go.dev/github.com/GizClaw/gizclaw-go/pkgs/audio/songs)

Songs package 拥有内置乐谱和合成逻辑，不拥有播放设备、用户 playlist 或产品资源 storage。
