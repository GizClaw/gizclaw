# pkgs/audio/codecconv

[源码](https://github.com/GizClaw/gizclaw/tree/main/pkgs/audio/codecconv)

连接 PCM、Ogg 与 Opus packages，提供 Ogg Opus encode/decode 和 packet/header conversion。

[Go API References](https://pkg.go.dev/github.com/GizClaw/gizclaw-go/pkgs/audio/codecconv)

该 package 只做格式转换，不决定媒体保存、网络发送或播放策略。
